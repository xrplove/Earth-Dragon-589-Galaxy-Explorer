# MyGalaxy

3D solar system you can explore in the browser.

https://galaxy.alkhabaz.dev

## Features

- All planets (Sun through Pluto)
- Guided tours
- Size comparison tool
- Distance measurements (AU)
- Toggleable effects (orbits, labels, trails, bloom)
- Keyboard shortcuts

## Run it

```
git clone https://github.com/Ialkyyyy/MyGalaxy.git
cd MyGalaxy
# Just open index.html — no build step
```

## Stack

Three.js
